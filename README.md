# 百智 AI 工作台 · In-meeting 需求演示

本仓库是 `agent-frontend-vue` 项目 `In-meeting` 分支上的**自包含需求演示应用**，用于演示 6 项新增需求的交互效果。数据均为 mock，零后端依赖，可直接静态部署。

## 演示内容

| 需求 | 说明 |
| --- | --- |
| 1.1 实时提问引导气泡 | 可手动修改问题后点「智能回答」发送；不默认消失、可手动关闭；下次提问覆盖显示 |
| 1.2 知识库文件全选 | 选择知识库文件弹窗新增全选功能 |
| 1.3 写下笔记整块输入 | 由逐条新增改为整块输入，换行自动生成时间戳 |
| 2.1-a 分享配置笔记模块 | 分享内容新增「笔记 - XX 条会中记录」及灰色引导文案 |
| 2.1-b 分享链接 Ask | 先引导登录才能 ask；无转译文本时检索优先级：实时翻译 → 总结；四类内容都无则不暴露 ask 入口 |
| 2.2 企业会议管理 | 管理员可查看下属所有员工会议数据（含笔记） |

## 本地运行

```bash
python3 -m http.server 8765
# 打开 http://localhost:8765
```

## 技术说明

- 纯 HTML + CSS + JavaScript，无任何构建依赖
- 视觉风格对齐百智工作台现有设计系统（主色 `#165DFF`）
- 参考交互原型：`完整原型2.0：会中笔记+实时总结+分享ask.html`
